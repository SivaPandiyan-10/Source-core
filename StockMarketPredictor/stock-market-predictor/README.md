# Stock Market Predictor Platform

A scalable, production-ready platform for predicting next-day stock movement probabilities for thousands of stocks.

## Features
- Daily data ingestion from Yahoo Finance
- Technical indicator generation (RSI, MACD, SMA, EMA, etc.)
- XGBoost-based AI model for next-day prediction
- FastAPI backend API
- Angular Material dashboard UI
- PostgreSQL/TimescaleDB for storage
- Redis caching for performance
- APScheduler for daily workflow
- Docker Compose deployment
