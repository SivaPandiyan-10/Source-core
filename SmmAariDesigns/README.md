# Smm Aari Designs (Angular 17+)

Original Angular 17 standalone website inspired by navigation hierarchy patterns from the reference site, implemented with fully dynamic JSON content.

## Run

```bash
npm install
npm run start
```

Open `http://localhost:4200/`.

## Build

```bash
npm run build
```

## Data-Driven Content

- Menu: `src/assets/data/menu.json`
- Routes: `src/assets/data/routes.json`
- Page content: `src/assets/data/pages/*.json`
- Gallery: `src/assets/data/gallery.json`
- Pricing: `src/assets/data/pricing.json`
- Site config: `src/assets/data/site-config.json`
- Social links: `src/assets/data/social-links.json`

Update JSON files to change navigation, content, pricing, gallery cards, and contact details without touching component code.
