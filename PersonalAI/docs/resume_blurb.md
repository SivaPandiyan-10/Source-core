Personal AI Assistant — local, privacy-first assistant built in C++ with modular LLM and RAG pipeline.

- Implemented a modular architecture: Core Engine, LLM interface (Ollama-friendly), Embedding microservice (Python), Memory Manager, Financial Module, RAG layer.
- Designed the system for local-only operation with SQLite persistent storage and a pluggable vector search layer.
- Implemented secure storage patterns and a prototype CLI demonstrating record-keeping, chat, and analytics.

This project highlights systems design, local LLM integration, data modeling, and production-minded C++ engineering.
